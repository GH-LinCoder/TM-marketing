The system is to create, build and manage any kind of organization. This is designed to allow anyone to start any kind of communal activity, such as a club, an association, a pressure group or even a start-up. Then to recruit others, build structure, automate onboarding, get feedback via surveys, create training or trasks. Then automate the workflow by linking together those tasks, surveys and structure. The steps are: Create an organisation by obtaining the rights to use an independent instance of the system. Define its purpose and aims. Recruit people. Ask questions and gather opinions using surveys. Train using tasks Create departments or interest groups or branches Build its structure by relating its parts. Who is in what branch doing which tasks. Assign responsibilities using the permission system. Create tasks and surveys and link them together into workflows and funnels. Automate responses to surveys or accomplishment of tasks Adapt the organisation as it evolves.
