# TM-marketing
SEO/LLM optimised site for TM. Static marketing for the project

The purpose is to publish a static site that contains details of the TM system separately from the deployed dashboards of the actual system.

The main reason is to that search engines can access the contents which are hidden behind permissions on the actual system. 

A secondary purpose could be human visitors.

The template page.html has default image, text and video, to be replaced with specific versions. Plus need to do:

 (Ctrl+H) to make all the metadata, breadcrumb, H1, canonical URL, and JSON-LD valid:

Replace [PAGE_FILENAME] with the filename (e.g., cadre).

Replace [PAGE_TITLE] with the page title (e.g., Activist Cadre & Skunk Works).
